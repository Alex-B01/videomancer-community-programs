# CBV Composite

**Status: Stage 2 (assembly) — not yet verified.**

CBV Composite puts the Syntonie CBV001 composite video bender on a virtual
composite signal path inside Videomancer. The incoming Y/U/V picture is
encoded to a composite signal (NTSC or PAL carrier, colour burst, virtual
sync, stepped Hue Bend), passed through a behavioural model of the CBV001's
2N7000 Enhance stage and its AC-coupled shelf/gain cell, and decoded by a
virtual TV: a sync separator with a selectable filter and AFC whose bent lock
tears the picture (held legal by Tame), a positionable clamp, a comb Y/C
split, and a burst-locked colour decoder with ACC, colour killer and PAL-S.
The decoded picture is read out on the true raster one line late, so the
output sync stays clean while the content bends.

## Controls

| Control | Name | Notes |
|---|---|---|
| Pot 1 | Enhance | 2N7000 Enhance row; tearing peaks near ≈ 850, the last ≈ 15 % restores sync |
| Pot 2 | Tame | soft limit of the bent horizontal displacement (quart_in taper) |
| Pot 3 | Leak | edges, bright picture and saturated colour leak into the separator |
| Pot 4 | Sep Filter | Narrow / Low / Mid / Wide / Open separator bandwidth |
| Pot 5 | Hue Bend | luma-driven 45° hue steps in the encoder |
| Pot 6 | Clamp Pos | moves the clamp window from the porch into the picture |
| Toggle 7 | Sync | Bent / Clean |
| Toggle 8 | Encode | NTSC / PAL |
| Toggle 9 | Decode | NTSC / PAL-S |
| Toggle 10 | AFC | Fast / Slow |
| Toggle 11 | Clamp Gain | Normal / Over |
| Slider | Colour | centre = locked; left = late burst; right = detune drift |

All 15 video timings are supported. Eight draft presets are included.
